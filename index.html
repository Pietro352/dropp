Dropp

Manda un file a un altro dispositivo, direttamente da browser a browser.

Come funziona
1
Condividi il tuo ID
Il tuo ID univoco (es. WOLF-4821) appare in alto. Copialo e mandalo all'altra persona tramite chat, email o SMS.
2
Inserisci l'ID dell'altro dispositivo
L'altra persona apre Dropp e ti manda il suo ID. Tu lo incolli nel campo "Connettiti a un dispositivo".
3
Stabilisci la connessione
Clicca Connetti. Dropp crea una connessione diretta tra i due browser.
4
Invia il file
Trascina un file nella zona tratteggiata. Il file viaggia direttamente tra i due dispositivi, senza essere salvato su nessun server.
Il file passa direttamente tra i browser e non viene mai caricato su un server. Entrambi i dispositivi devono tenere aperta la pagina durante l'invio.
